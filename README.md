# Little Sunshine Play School — Official Website

A responsive preschool website with a private administrator dashboard for uploading, captioning, editing and deleting photos and videos.

## What's included

- Public homepage, About, Activities, Photo Gallery, Video Gallery and Contact sections.
- School logo supplied for this project (`public/logo.jpeg`).
- Private admin sign-in at `/admin.html`.
- Admin can upload photos and videos, add/edit captions and descriptions, and delete items.
- SQLite database for gallery metadata and sessions.
- Persistent upload folder and database path configurable for Render.
- Login rate limiting, session cookies, upload type/size limits and protected management routes.
- Responsive layouts for mobile, tablet and desktop.

## 1. Run on your computer (Windows)

1. Install **Node.js 20 or newer** from https://nodejs.org/.
2. Extract this ZIP folder.
3. Open the extracted `little-sunshine-website` folder.
4. Copy `.env.example` and rename the copy to `.env`.
5. Open `.env` in Notepad. The initial login is:
   - Username: `7032070594`
   - Password: `773200`
6. Change `SESSION_SECRET` to a long random string (at least 32 characters). Change the admin password to a strong, private password before publishing.
7. Open Command Prompt in this folder and run:

   ```bash
   npm install
   npm start
   ```

8. Open http://localhost:3000 for the public website.
9. Open http://localhost:3000/admin.html to sign in and manage gallery content.

The local database and uploaded files are stored in `data/`.

## 2. Publish with GitHub and Render

**Important:** the Render configuration in `render.yaml` uses a persistent disk mounted at `/var/data`. This is necessary because uploaded photos/videos and the SQLite database must survive restarts and deployments. Render persistent disks require a paid web-service plan; confirm current pricing in your Render account before deploying. Do not deploy this upload-based site on an ephemeral filesystem if you need to keep media.

1. Create a new empty GitHub repository, for example `little-sunshine-play-school`.
2. Extract this project ZIP. Do not upload `node_modules`, `.env`, or private school media to GitHub.
3. Upload the project files and folders to the repository and commit them. Make sure `package.json`, `server.js`, `render.yaml`, `public/` and `data/.gitkeep` are in the repository root.
4. Sign in to https://render.com and choose **New + → Blueprint**. Connect GitHub and select this repository. Render reads `render.yaml` and creates the web service and persistent disk.
5. When Render asks for the two secret values, set:
   - `ADMIN_USERNAME`: `7032070594` (or change to a different private username)
   - `ADMIN_PASSWORD`: choose a strong password. The supplied six-digit starter password is weak and should not be used on a public website.
6. `SESSION_SECRET` is generated by the Blueprint. Keep it private. Confirm the disk is mounted at `/var/data` and the environment values `DATA_DIR=/var/data` and `UPLOAD_DIR=/var/data/uploads` are set.
7. Deploy. When the build finishes, open the `onrender.com` URL shown by Render. Admin: append `/admin.html`.

If you create a Render Web Service manually instead of using the Blueprint, use:
- Runtime: Node
- Build command: `npm install`
- Start command: `npm start`
- Health check path: `/api/health`
- Persistent disk mount path: `/var/data`
- Environment variables: `NODE_ENV=production`, `DATA_DIR=/var/data`, `UPLOAD_DIR=/var/data/uploads`, `ADMIN_USERNAME`, `ADMIN_PASSWORD`, and a long random `SESSION_SECRET`.

## 3. Customise the school contact details

Open `public/index.html` in GitHub or a code editor and search for `ADD-SCHOOL-EMAIL-HERE`. Replace it with the school's real official email address. Add the confirmed school phone number, address, opening hours, admission information and social links before sharing the site publicly. These details were not supplied, so sample contact details have deliberately not been invented.

To replace the logo, keep the new image named `logo.jpeg` and replace `public/logo.jpeg`.

## 4. How to manage photos and videos

1. Visit your live website and open `/admin.html`.
2. Sign in with the administrator credentials stored in Render environment variables.
3. Select a photo or video, enter an optional caption and description, and upload.
4. The new item appears in the public gallery automatically.
5. Use **Save changes** to update captions/descriptions or **Delete** to permanently remove an item and its uploaded file.

Supported formats: JPG, PNG, WEBP, GIF, MP4, WEBM and MOV. Maximum upload size is 150 MB per file. Large videos can take time to upload; use compressed MP4 videos for smoother loading on parents' phones.

## 5. Important operational notes

- Keep `.env` private. Never commit it to GitHub. `.gitignore` excludes it.
- The public website does not show admin credentials. The admin dashboard is not linked prominently; it is available at `/admin.html`.
- The first login password is only a starting credential. Change it before deployment and keep it private.
- Back up the Render persistent disk/database and media files regularly. A persistent disk protects files across deploys/restarts but is not a substitute for backups.
- Do not upload children's identifiable photos/videos without the school's appropriate parent/guardian consent. Consider limiting access to sensitive media and publishing only content approved for public viewing.
- The contact section currently contains a placeholder email. Update it before launch.
